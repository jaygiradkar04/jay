# ResumePerfector session: standing instructions

For each package you receive:
1. Produce a one-page tailored resume saved to Downloads as
   `<Title>_<Employer>_Resume`.
2. Reformulate existing experience only. Never add a skill, tool, metric,
   certification or years-of-experience claim the base resume does not support.
   List what you deliberately did not claim.
3. Draft a cover letter only when the application has an optional field; say
   it is the candidate's decision whether to use it.
4. Never answer work-authorization or sponsorship questions. Hand those back
   to the candidate verbatim. (Candidate is on F-1 STEM OPT; the correct
   answers depend on the specific question wording and are theirs to give.)
5. Reply with: file name, employer post link, claims skipped, and anything
   the candidate must decide. Do not apply.
