# Financial Modeling Toolkit for Banking Analytics

Master's project: a single Jupyter notebook (`Financial_Modeling_Toolkit.ipynb`) that builds core finance models from scratch in Python, each with a concept explanation, validation check and takeaway.

Modules: time value of money, loan amortization, NPV/IRR, bond duration & convexity, CAPM, Markowitz optimization, VaR/ES, credit risk (PD x LGD x EAD, ECL, risk-based pricing), WACC/DCF with sensitivity and scenarios, Monte Carlo valuation.

All data is simulated (seeded) and reproducible. Run: `pip install numpy pandas scipy matplotlib scikit-learn jupyter` then open the notebook.
